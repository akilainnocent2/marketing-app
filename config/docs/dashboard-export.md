# Dashboard exports and mobile dialogs

The dashboard retains its existing scope, default-period selection, marketer selection,
model permissions, and commission calculations. PDF and Excel receive the same payload
from `get_dashboard_export()`, which calls the existing dashboard data/metric helpers.
Location and descendant filtering affects expenditure/customers; eligible sales and
commission still cover the marketer's whole configured period. `period=` is ignored.

## Changes

Modified files (relative to `config/`):

- `api/dashboard.py`: shared bounded payload and safe attachment filenames.
- `api/views.py`, `api/urls.py`: authenticated chooser/PDF/XLSX routes, independently
  requiring `view_reports` and `export_reports`; existing model permissions are retained.

  wrapped tables, repeating headers, section counts/totals, and numbered footers.

- `api/test_dashboard.py`: 11 new regressions and the updated six-anchor semantic test.

Downloads retain normal attachment links and browser download handling, including when
JavaScript is disabled. There is no simulated loading progress. Invalid scope returns
400, unauthorized access returns 403 (anonymous direct requests redirect to login),
and more than 5,000 combined detail records returns 422 before either renderer runs.
Restricted model sections are marked “Not permitted”; missing commission policies are
explicitly identified instead of presented as zero-rate policies.

## Mobile behavior

At widths up to 600px, dashboard drill-down/export dialogs are full-width bottom sheets
with rounded top corners and a maximum height of 92dvh. Content scrolls inside the
sheet with safe-area bottom padding; the 44px close control stays outside that scrolling
content. The background stays fixed, and closing restores its scroll position and the
opening control's focus. Native dialog focus containment and Escape remain in use.
The 180ms entrance is disabled under reduced motion. Other dialogs keep their layout.

The two format choices stack into large touch cards on phones. Detail tables keep
14px text, minimum 140px cells, right-aligned money, and their own horizontal scrolling;
pagination stays outside that region. Dashboard cards use one column through 600px,
two through 1100px, then three, including very wide screens.
